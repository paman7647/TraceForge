## Release History Overview

- **`v1.0.0` (2026-08-25)**: Production-ready release.
  - Multi-ecosystem package catalog supporting 152 tools.
  - Adaptive dual runtime engine (Python 3 + compiled Go fast-paths).
  - 7 specialized investigation modules covering media, PCAP, identity, email, DNS, documents, and OPSEC.
  - Multi-format reporting subsystem (Markdown, HTML, CSV, STIX 2.1, MISP, GeoJSON, KML).
  - Native Termux / Android environment support.
  - PyPA PyPI packaging (`traceforge-osint`).

For full release highlights, see [RELEASE_NOTES.md](https://github.com/paman7647/TraceForge/blob/master/RELEASE_NOTES.md).
